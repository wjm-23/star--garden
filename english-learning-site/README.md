# LinguaFlow 英语学习站

这是一个独立的英语学习网站，和现有的花园项目完全分开，不会修改原项目代码。

## 运行方式

在本地终端运行：

```bash
cd english-learning-site
python -m http.server 8000
```

打开浏览器访问：

```text
http://localhost:8000
```

## 站点内容

- 英语学习首页
- 课程路线介绍
- 今日词汇卡片
- 语法与词汇小测试
- 学习社区与目标展示

## 说明

这个站点使用纯 HTML + CSS + JavaScript，便于快速预览和二次开发。
